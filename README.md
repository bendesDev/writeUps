# Security Write-Ups
Este repositório reúne write-ups de máquinas retiradas do HackTheBox, salas do TryHackMe e desafios de CTF, documentados com a mesma estrutura usada em relatórios profissionais de pentest: reconhecimento, obtenção de acesso, escalação de privilégio, causa raiz e remediação. O objetivo é registrar não só o "como", mas o raciocínio por trás de cada decisão técnica.
